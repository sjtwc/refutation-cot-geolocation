# AIST4010 — Refutation-Guided Chain-of-Thought for Vision-Based Geolocation

Course project (CUHK AIST4010, Dec 2025) investigating whether fine-tuning a vision-language
model on refutation-style reasoning traces improves country-level geolocation from street-view
images.

The method fine-tunes `llava-hf/llava-v1.6-mistral-7b-hf` with 4-bit QLoRA on 967 synthetic
reasoning traces generated by Grok-4 from GeoGuessr-50K images. Two trace styles are included:
refutation-CoT and normal-CoT.


## Layout

```
src/geoloc/train/   Original QLoRA training scripts (refutation, normal)
src/geoloc/eval/    Original inference/evaluation scripts
scripts/            Test-set construction scripts
notebooks/          Synthetic CoT generation notebook
data/synthetic/     967 refutation traces and 967 normal traces
data/manifests/     Synthetic image pool (6,434 images)
data/reference/     Country coordinates and metadata
results/raw/        Archived evaluation outputs (unverified)
artifacts/          LoRA adapter zips (not tracked in Git)
reports/            LaTeX and PDF report
tests/              Tests for the upcoming refactor
```

## Data and artifacts

- The GeoGuessr images are not included. Download GeoGuessr-50K separately.
- The two LoRA adapters are stored in `artifacts/checkpoints/` and are intended for private
  Hugging Face model repositories, not Git.
- `data/synthetic/refutation_1k_final.json` and `normal_1k_final.json` contain the same 967
  images in the same order; only the assistant reasoning differs.
