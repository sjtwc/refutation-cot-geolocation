# Refutation-Guided Chain-of-Thought for Vision-Based Geolocation

Refactored based on my aist4010 course project investigating whether fine-tuning a vision-language
model on refutation-style reasoning traces improves country-level geolocation from street-view
images.

The method fine-tunes `llava-hf/llava-v1.6-mistral-7b-hf` with 4-bit QLoRA on 967 synthetic
reasoning traces generated by Grok-4 from GeoGuessr-50K images. Two trace styles are compared:
refutation-CoT and normal-CoT.


## Layout

```
src/geoloc/countries.py        Country aliases and label canonicalization
src/geoloc/parsing.py          Strict country extraction (no ground-truth fallback)
src/geoloc/metrics.py          Accuracy, coverage, per-country and confusion tables
src/geoloc/manifest.py         Manifest loading, hashing, image-path resolution
src/geoloc/train/sft.py        Config-driven QLoRA trainer (refutation or normal)
src/geoloc/eval/evaluate.py    Frozen-manifest evaluator for base model or adapter
src/geoloc/eval/model_loader.py Base/adapter loading with CUDA 4-bit and dtype options
scripts/build_manifests.py     Build training-disjoint 4,800/1,000 eval manifests
scripts/rescore_results.py     Re-score archived outputs with the strict parser
scripts/release_gate.py        Paired accuracy/coverage/McNemar release gate
notebooks/                     Synthetic CoT generation notebook
data/synthetic/                967 refutation traces and 967 normal traces
data/manifests/                train_967, eval_4800, eval_1000, manifest_index
data/reference/                Country metadata and alias map
results/raw/                   Archived evaluation outputs (unverified)
results/tables/rescored/       Corrected scores from the archived outputs
artifacts/                     LoRA adapter zips (not tracked in Git)
reports/                       LaTeX and PDF report
tests/                         Parser, metric, and manifest tests
```

## Data and splits

- GeoGuessr images are not included; download GeoGuessr-50K separately.
- `refutation_1k_final.json` and `normal_1k_final.json` contain the same 967 images in the
  same order; only the assistant reasoning differs.
- The synthetic image pool has 6,434 images. All 967 training images are excluded before
  sampling the frozen evaluation sets.
- `eval_4800.json` contains 4,800 images; `eval_1000.json` is a nested 1,000-image subset.
  Neither overlaps training. See `data/manifests/manifest_index.json` for hashes and seeds.
- `true_lat`/`true_lon` in the synthetic traces are country centroids plus noise, not GPS
  coordinates. For that reason this project reports country accuracy only, not distance or
  `@25km` metrics.

```bash
python scripts/build_country_aliases.py
python scripts/build_manifests.py
PYTHONPATH=src python -m unittest discover -s tests -v
```

## Training

Training needs a CUDA GPU with `bitsandbytes`, `peft`, `trl`, and `transformers`. The image
root is the directory that contains `compressed_dataset/`.

```bash
python src/geoloc/train/sft.py \
  --mode refutation \
  --image-root /path/to/dataset \
  --output-dir artifacts/checkpoints/refutation \
  --report-to none
```

`--mode normal` uses the normal-CoT traces; both modes share the same trainer and
hyperparameters.

## Evaluation

```bash
# Zero-shot base model
python src/geoloc/eval/evaluate.py \
  --manifest data/manifests/eval_1000.json \
  --image-root /path/to/dataset \
  --adapter none \
  --output artifacts/predictions/base_eval1000.json

# Fine-tuned adapter (private Hugging Face repo)
python src/geoloc/eval/evaluate.py \
  --manifest data/manifests/eval_1000.json \
  --image-root /path/to/dataset \
  --adapter sjtwc/llava16-refutation-cot-geoguessr \
  --output artifacts/predictions/refutation_eval1000.json
```

The evaluator writes predictions plus `summary.json`, `per_country.csv`, and
`confusion_matrix.csv`. Unparsed responses count as wrong and are never mapped to a
ground-truth country. Private adapters need `hf auth login` or `HF_TOKEN`.

On macOS, install `peft` and use bf16 on MPS. Full 4-bit is CUDA-only; the evaluator
rejects `--load-in-4bit` on MPS/CPU:

```bash
pip install peft
python src/geoloc/eval/evaluate.py ... --dtype bfloat16 --device-map auto
```

For a free Colab T4, use NF4 4-bit and fp16, put outputs on Google Drive, and resume
after disconnects. Run `--limit 10` once to check memory and speed:

```bash
pip install -U transformers accelerate peft bitsandbytes
python src/geoloc/eval/evaluate.py \
  --manifest data/manifests/eval_1000.json \
  --image-root /content/drive/MyDrive/geoguessr \
  --adapter sjtwc/llava16-refutation-cot-geoguessr \
  --load-in-4bit --dtype float16 --device-map auto --resume \
  --output /content/drive/MyDrive/predictions/refutation_eval1000.json
```

To reproduce the corrected archived numbers:

```bash
python scripts/rescore_results.py
```

The release gate requires a 5 pp gain over zero-shot, a significant McNemar test against
normal-CoT (`p < 0.05`), and at least 95% parse coverage on the same frozen manifest:

```bash
python scripts/release_gate.py \
  --refutation artifacts/predictions/refutation_eval1000.json \
  --baseline artifacts/predictions/base_eval1000.json \
  --normal artifacts/predictions/normal_eval1000.json
```

## Adapters

Both adapters are private, unverified checkpoints on Hugging Face:

- `sjtwc/llava16-refutation-cot-geoguessr`
- `sjtwc/llava16-normal-cot-geoguessr`

Each uses PEFT LoRA with rank 64, alpha 16, and targets
`q/k/v/o/gate/up/down_proj`. The base model and image data are not redistributed.

## Metrics

- **Country accuracy**: correct / all images; unparsed predictions are wrong.
- **Parse coverage**: responses with a usable country / all images.
- **Accuracy | parsed**: correct / parsed responses.
- **Per-country accuracy** and **confusion matrix**: written for every run.

Because the labels are country-level and the coordinates are synthetic, distance-based
GeoGuessr scores are not reported.
